# Getting started

## Requirements

- Bun and Node.js (versions pinned in `aqua/aqua.yaml`)
- Doppler CLI
- Wrangler (installed with `bun install`)
- OpenTofu 1.13.9+ for infrastructure changes
- A Cloudflare account for deployment

Bun, Node.js, Doppler, and OpenTofu are installed by
[aqua](https://aquaproj.github.io/) from `aqua/aqua.yaml` (registry entry in
`aqua/registry.yaml`). CI and the devcontainer install the same checksum-verified
releases via `.github/actions/setup-deps`, which also caches aqua and Bun.

## Local setup

`doppler.yaml` selects the `web` project and `dev_personal` config.

```sh
doppler login
doppler setup
doppler run -- bun install
bun run db:migrate
bun run db:seed
bun run dev
```

- `bun run dev` runs Astro through `doppler run`; secrets come from Doppler, while public Worker variables stay in `wrangler.json`.
- `doppler run -- bun install` supplies `NODE_AUTH_TOKEN` for the GitHub Packages registry in `.npmrc`.
- `bun install` runs Panda codegen and `wrangler types`. The generated `src/types/worker-configuration.d.ts` is gitignored.
- `bun run db:seed` creates local events, forms, registrations, payments, check-ins, status links, and the `admin@example.com` (admin) and `staff@example.com` (staff) accounts with password `dev-password`.

Useful URLs:

- Event list: `http://localhost:4321/en/events/`
- Registration: `http://localhost:4321/en/events/registration?slug=summer-picnic-2027`
- Admin catalog: `http://localhost:4321/en/admin/events`

The development staff fallback is compiled behind `import.meta.env.DEV` and does not run in staging or production.

## Environment variables

Local development reads `dev_personal`; deploys read `stg` and `prd`. Public Worker variables are committed in `wrangler.json`; the Turnstile site key and all secrets come from Doppler.

| Variable                                                                              | Purpose                                      |
| ------------------------------------------------------------------------------------- | -------------------------------------------- |
| `NODE_AUTH_TOKEN`                                                                     | GitHub Packages token used during install    |
| `TURNSTILE_SITE_KEY`                                                                  | Public site key, generated by OpenTofu       |
| `TURNSTILE_SCRIPT_URL`, `TURNSTILE_VERIFY_URL`                                        | Turnstile endpoints                          |
| `TURNSTILE_SECRET`                                                                    | Turnstile server secret (Wrangler secret)    |
| `BETTER_AUTH_SECRET`                                                                  | Better Auth signing secret (Wrangler secret) |
| `EMAIL_PROVIDER`                                                                      | `gmail` (default) or `mailtrap`              |
| `GMAIL_CLIENT_ID`, `GMAIL_CLIENT_SECRET`, `GMAIL_REFRESH_TOKEN`                       | Gmail OAuth (secrets)                        |
| `GMAIL_SENDER_EMAIL`, `GMAIL_SENDER_NAME`                                             | Sender identity / send-as alias              |
| `GMAIL_TOKEN_URL`, `GMAIL_SEND_URL`                                                   | Google OAuth token and Gmail send endpoints  |
| `MAILTRAP_API_TOKEN`, `MAILTRAP_API_URL`, `MAILTRAP_FROM_EMAIL`, `MAILTRAP_FROM_NAME` | Optional Mailtrap fallback                   |

Secrets: `TURNSTILE_SECRET`, `GMAIL_CLIENT_ID`, `GMAIL_CLIENT_SECRET`, `GMAIL_REFRESH_TOKEN`, `BETTER_AUTH_SECRET`, and the optional `MAILTRAP_API_TOKEN`.

The Better Auth base URL is injected at build time by the `better-auth-url` Astro integration from the active custom-domain route in `wrangler.json`; local development uses `http://localhost:4321`.

For Cloudflare Web Analytics, set `PUBLIC_CLOUDFLARE_ANALYTICS_TOKEN` in Doppler. Leaving it empty omits the beacon. Analytics reports page views, referrers, and Core Web Vitals, not JS exceptions — use Workers Logs or Sentry for errors.
